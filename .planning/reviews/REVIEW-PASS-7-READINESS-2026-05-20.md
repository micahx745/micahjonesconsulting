**H2 — Person JSON-LD description hasn't been updated to match the cap-table framing Pass-4 nailed.** `app/layout.tsx:69` description says *"...$17M+ in client revenue (2013–2023). **H3 — No `forced-colors` / Windows High Contrast Mode handling anywhere in `globals.css`.** `grep -n forced-colors app/globals.css` returns zero hits. Under Windows High Contrast Mode, the terracotta/petrol/bone/espresso palette collapses to system colors and the mix-blend-mode wordmark + the magnetic CTAs + the SVG grain layers + the chromatic-aberration text-shadow all behave unpredictably. WCAG 1.4.3 AA contrast is fine under default-colors; WCAG 1.4.11 (non-text contrast) and the Forced Colors Mode contract (WCAG 1.4.6 AAA territory but increasingly expected for consultant-tier sites in 2026) are not. **Fix:** add a `@media (forced-colors: active) { ... }` block that pins `[data-mode="cw"]` foreground to `CanvasText`, background to `Canvas`, accent to `LinkText`, and disables the grain/halftone/chromatic-aberration layers (which become opaque blockers under forced-colors).

### MEDIUM

**M1 — No print stylesheet at all.** `grep -n '@media print' app/globals.css` returns zero hits. Printing `/work/ordani` produces black pages from the theater mode with the chromatic-aberration text-shadow over-rendered. Not a frequent path — but consultant portfolios get printed for procurement reviews and board-deck inserts more often than designers think. **Fix:** add `@media print { [data-mode="cw"] { background: white !important; color: black !important; } .cw-grain, .cw-grain__fine, .cw-grain__halftone, .cw-marquee, .cw-companies { display: none !important; } .cw-h1 .cw-line > span, .cw-eyebrow > span { transform: none !important; } /* same for theater */ }`.
