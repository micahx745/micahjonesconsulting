## BLOCKERS

### B1 — "TheValidate" is a misspelling. The company is **TechValidate**.
- (a) The exits credibility line and the Companies marquee both name the second acquired company "TheValidate." It's **TechValidate** (acquired by SurveyMonkey, August 2015). Anyone who knows the deal, or who Googles the name from your page, finds nothing. The credibility moment that anchors the entire site dies on the single most visible word.
- (b) `app/(foyer)/page.tsx:74` (`COMPANIES` array, `"TheValidate"`); `components/color-worlds/RevenueTick.tsx:103` (`<strong>TheValidate</strong>`).
- (c) Global find-and-replace `TheValidate` → `TechValidate`. Also confirm `og:image` text and any OG composition for the home doesn't echo the misspelling.

### B2 — Revenue line ships `$0.0M` server-side.
- (a) `RevenueTick` uses `useState("$0.0M")` and animates to `$17M+` only after IntersectionObserver fires post-hydration. The SSR HTML literally contains "`$0.0M in revenue, generated.`" (I confirmed it in the deployed HTML). On any slow-JS, JS-disabled, or pre-hydration paint, the page's credibility headline reads as **zero revenue**.
- (b) `components/color-worlds/RevenueTick.tsx:30` — initial state.
- (c) Default state to `"$17M+"` (the target). On mount, if `prefers-reduced-motion` is off, snap back to `$0.0M` and re-tick. Static-by-default, animated-as-progressive-enhancement — never the other way around for a credibility number.

### B3 — Hero is JS-dependent for visibility.
- (a) Eyebrow, headline lines, sub, and CTA row all start at `transform: translateY(110%)` / `opacity: 0` in CSS and are unblurred by `Hero.tsx` via inline JS. Without JS (or pre-hydration), the entire above-the-fold is invisible. The brief asked "what happens with JS disabled" — the answer is "a blank hero."
- (b) `app/globals.css` lines 5485-5506 (eyebrow + cw-h1 .cw-line > span), 5525-5566 (cw-sub + cw-cta-row); `components/color-worlds/Hero.tsx` lines 33-64.
- (c) Same pattern you already use for `.cw-reveal`: default to visible, then hide only when a JS-set class (e.g. `.cw-js-reveals`) is present on the root. Move the initial-hidden state behind `[data-mode="cw"].cw-js-reveals .cw-eyebrow > span { transform: translateY(110%); }`. Identical visual result, but no-JS clients see content.

### B4 — `/about`, `/work`, `/work-with-me`, `/contact` are listed in the sitemap but render broken under the Color Worlds layout.
- (a) Those four pages use `.foyer-page` / `.foyer-hero` / `.foyer-prose` classes scoped to `[data-mode="foyer"]` in CSS, but `app/(foyer)/layout.tsx` now sets `data-mode="cw"`. The classes match nothing — the pages would render as unstyled HTML on a terracotta bg with the Color Worlds nav stuck on top. Today's live `/about` renders the OLD foyer nav ("MICAH JONES" wordmark, /work-with-me link), so production is currently inconsistent: home is Color Worlds, /about is old foyer. The sitemap is telling Google to index this mess.
- (b) `app/sitemap.ts:21-52`; `app/(foyer)/about/page.tsx`, `/work/page.tsx`, `/work-with-me/page.tsx`, `/contact/page.tsx` (uses `.foyer-*` classes); CSS scope at `app/globals.css:3487+`.
- (c) Decide for each: either delete the page + drop it from the sitemap, or rewrite it in `.cw-*` classes. The home is a single-page narrative now — `/about` and friends probably shouldn't exist as separate routes. Drop them, drop the sitemap entries, drop the (foyer)/contact/layout.tsx scaffolding.

### B5 — The entire Color Worlds direction is uncommitted in git.
- (a) `git status` shows `components/color-worlds/`, `app/v1/`, `app/v4/`, `app/actions/beta-signup.ts`, `lib/motion/` as untracked, plus modified `app/(foyer)/layout.tsx`, `page.tsx`, `globals.css`, `layout.tsx`, `fonts.ts`. There is zero commit history of "color worlds." One `git reset --hard` and the entire direction is gone. The deployed site is somehow ahead of `main` — either built from a preview branch or from a dirty working tree.
- (b) Repo root.
- (c) Branch, commit, push before anything else. Verify the Vercel production deployment is pointing to a real `main` commit and not a stale build artifact.

### B6 — Title is double-suffixed.
- (a) Live `<title>` reads "Micah Jones — Strategy and software, shipped by the same pair of hands — Micah Jones." `app/(foyer)/page.tsx` exports the full title; root `app/layout.tsx` sets `title: { template: "%s — Micah Jones" }`. The template wraps the page title and produces the duplicate suffix.
- (b) `app/layout.tsx:32-34` + `app/(foyer)/page.tsx:27`.
- (c) Either set the home title to `{ absolute: "Micah Jones — Strategy and software, shipped by the same pair of hands" }` so the template doesn't apply, or drop the template entirely and have every page set its full title.

### B7 — OG / canonical URL is a tangle of two domains.
- (a) `metadataBase` is `https://micahjonesconsulting.vercel.app` (root layout). Home `openGraph.url` is `https://micahjonesconsulting.com`. Sitemap and `robots.txt` both reference `.com`. The live sitemap at `vercel.app/sitemap.xml` therefore lists URLs at a different host than the one serving it — Search Console will flag this as a cross-host sitemap and refuse to validate. `metadataBase` also resolves OG images to `vercel.app/...`, so link unfurls point at the staging domain while link clicks point at the apex.
- (b) `app/layout.tsx:41`, `app/sitemap.ts:16`, `app/robots.ts:46-47`.
- (c) Pick the apex. Either set `metadataBase` to `https://micahjonesconsulting.com` and finish the DNS work, or temporarily set the sitemap and robots to the `vercel.app` host. Inconsistent domains across these three files is the worst of every option.

### B8 — `EditorialTimestamp` leaks "Oakland · May 2026 · Issue 01" into the SSR HTML on Color Worlds pages.
- (a) The component mounts in the root layout. CSS hides it via `body:has([data-mode="cw"]) .editorial-timestamp { display: none !important; }`. That hides the visual element, but the text is still in the SSR HTML — confirmed in WebFetch output, which captures the markdown-extracted "Oakland¶May 2026¶Issue 01" trailing every Color Worlds page. Screen readers and crawlers ignore `display: none`-set ARIA hidden? No — `display: none` does hide from AT, so SR users are fine. But the text **is** in the DOM and **is** crawler-visible. Google may surface "Oakland · May 2026 · Issue 01" as a page snippet.
- (b) `app/layout.tsx:59` mounts unconditionally; `app/globals.css:6135-6137` hides via CSS.
- (c) Conditionally render the component — e.g. read the route segment server-side, or restructure so it only mounts under `(theater)` / `/v1` / `/v3` / `/v4`. Stop relying on CSS to hide content from crawlers.

### B9 — `/v1` and `/v4` are NOT noindex; only `/v2` and `/v3` are.
- (a) Brief stated all four legacy direction snapshots are noindex. They're not. `app/v1/layout.tsx` and `app/v4/layout.tsx` export no `robots` metadata. Both are crawlable and Google will index them on any direct link. Anyone benchmarking your iteration history hits a rejected design ranked next to the home.
- (b) `app/v1/layout.tsx`, `app/v4/layout.tsx`.
- (c) Add `export const metadata: Metadata = { robots: { index: false, follow: false } };` to both, matching v2/v3.

## HIGH

### H1 — Five fonts preload on every page.
- (a) `lib/fonts.ts` sets `preload: true` for Bricolage, Inter Display, Inter, Fraunces, and Hanken Grotesk. Only Bricolage + Hanken (+ JetBrains Mono, which is `preload: false`) are used on Color Worlds. Inter Display + Inter + Fraunces preload anyway, on the home, for the benefit of /v1, /v2, /v4 routes the visitor will never see. That's likely 200-400KB of woff2 on the critical path that produces zero pixels.
- (b) `lib/fonts.ts:43, 53, 102`.
- (c) Set `preload: false` on Inter, Inter Display, and Fraunces. Their pages are noindex (post-B9) and the route group does its own font cascade — they don't need to be on the home's critical path.

### H2 — Skip-to-content link is invisible on the Color Worlds hero.
- (a) Skip link background is `--color-accent-copper-deep` (#8A3D24), foreground `--color-foyer-paper` (#F5EFE4). On the terracotta hero bg (#9E3C25), the link's bg differs from the page bg by ~3 hex units — the focused link disappears against the hero. First keyboard tab stop is functionally hidden.
- (b) `app/globals.css:5075-5099`.
- (c) Add a `[data-mode="cw"] .skip-to-content` rule that uses `--color-cw-espresso` bg + `--color-cw-bone` fg. Or, simpler: outline the link in `--cw-accent` and let the bg be `--cw-bg` so it's visible regardless of world.

### H3 — Mobile nav dialog has no ESC-close, no focus trap, no return-focus.
- (a) `cw-overlay` has `role="dialog"` + `aria-modal="true"` — claims to be a modal but has none of the modal behaviors. Press Tab inside it on a wide screen with `cw-navlinks` visible: focus escapes. Press ESC: nothing happens. Tap the close button: focus jumps to the document, not back to the menu trigger.
- (b) `components/color-worlds/Nav.tsx:66-92`.
- (c) Add a keydown handler for Escape → `setOpen(false)`. On open: store `document.activeElement`, focus the close button; on close: restore previous focus. Trap focus inside the overlay while open (simple `focusin` listener pattern). 15 lines of code; basic for a `role="dialog"`.

### H4 — Five legacy directions mount on every visit via Lenis + EditorialTimestamp + nine font families.
- (a) The root layout loads NINE font families and wraps everything in Lenis. Lenis intercepts wheel events globally and rewrites scroll behavior across /v1-/v4 and the home. Each of those routes was designed with different scroll expectations. Lenis-everywhere also means the home's in-page anchor links (`#clients`, `#ordani`, etc.) go through Lenis's smoothing instead of native instant-jump — works, but harder to debug.
- (b) `app/layout.tsx:25, 52, 56`.
- (c) Scope Lenis to the cw route group, not root. Same for any nine-font preloading. The root layout shouldn't know about Color Worlds.

### H5 — The rolling word in `Hero` is announced repeatedly by screen readers.
- (a) `.cw-stack` cycles every 1.9s. There's no `aria-hidden` on the rolling stack and no static SR-only fallback. A blind user lands on the hero and hears "I build the product. I build the pipeline. I build the launch. I build the system." cycling forever.
- (b) `components/color-worlds/Hero.tsx:139-148`.
- (c) Add `aria-hidden="true"` to the `<span class="cw-roll">` and add a visually-hidden static sibling: "I build the system." — a single line for SR consumption.

### H6 — Pointermove parallax on the hero h1 has no rAF batching.
- (a) `Hero.tsx:110-114` writes `h1.style.transform` directly on every `pointermove` event. Modern mice fire at 240-1000Hz. The h1 carries `.cw-shift` (text-shadow chromatic aberration), which creates a compositing layer — combined with high-frequency transforms, this produces visible jitter on the headline shadows. Burns battery on laptops.
- (b) `components/color-worlds/Hero.tsx:97-117`.
- (c) Batch via rAF: store the latest `dx/dy` in refs, schedule a single rAF per frame to apply the transform. Or skip the parallax entirely — see L1 below.

### H7 — `pnpm-lock.yaml` ships two React versions.
- (a) `node_modules/.pnpm` contains both `next@16.2.6_react@19.2.4` and `next@16.2.6_react@19.2.6` trees, plus matching `react@19.2.4` and `react@19.2.6` installs. Some transitive dep is pulling 19.2.4 alongside the root's 19.2.6. In production this means two React bundles loadable in the same page if any nested package imports its own copy.
- (b) `pnpm-lock.yaml`, root `package.json`.
- (c) `pnpm dedupe`, then `pnpm install`, then verify only one React version in the lockfile. If the duplicate is a peer-dep conflict, pin the offending package or override via `pnpm.overrides`.

### H8 — `lib/motion/tokens.ts` is unused by Color Worlds.
- (a) The file claims (in its header) that "every animation in the codebase MUST resolve to a value here." Grep confirms zero imports from `@/lib/motion/tokens` anywhere in `components/color-worlds/`. The cw direction inlines durations (`.6s`, `.9s`, `2.4s`) and easings (`cubic-bezier(0.16, 1, 0.3, 1)`) directly. The "claimed source of truth" is decoration.
- (b) `lib/motion/tokens.ts`; grep `components/color-worlds/ -r "tokens"` returns nothing.
- (c) Either import `DURATION` and `EASE` into the cw components and `globals.css` (via CSS vars), or delete `tokens.ts` and the header docstring claim. Don't both inline magic numbers and write a manifesto against them.

### H9 — 227KB of GSAP+ScrollTrigger+SplitText+Lenis on a page that uses two character cascades and one marquee.
- (a) The only visible GSAP work is the SplitText cascade on two `<h2>` titles (Clients + Products). ScrollTrigger fires that. Lenis smooths the wheel. The hero rolling-word is plain `setInterval`. The companies marquee is pure CSS keyframes. So all 200+KB of GSAP buys you a per-character delay on two headlines.
- (b) `components/color-worlds/SplitReveal.tsx`, `components/LenisProvider.tsx`, `package.json` deps.
- (c) Replace `SplitReveal` with a 30-line custom `<SplitChars>` that wraps each char in a span and animates via CSS keyframes triggered by an IntersectionObserver. Replace Lenis with native CSS smooth-scroll (set `scroll-behavior: smooth` on `html` and trust the platform). You delete two of the three biggest deps. LCP improvement should be real but I haven't measured.

### H10 — `pointermove`-driven setInterval keeps the rolling word ticking when the hero is off-screen / tab is hidden.
- (a) The interval never pauses. `setInterval` is throttled to ~1Hz by browsers when the tab is hidden, but it still runs. When the tab regains focus, it catches up — the rolling word may snap several steps at once. On long sessions or low-end Android, the timer drift becomes visible.
- (b) `components/color-worlds/Hero.tsx:67-95`.
- (c) Pause on `document.visibilityState === "hidden"`; resume on visibility change. Or pause when the hero leaves the viewport (use the same IntersectionObserver pattern as RevenueTick).

### H11 — Companies marquee duplicates the "Two exits" claim.
- (a) The Companies marquee lists "Guardicore Akamai TheValidate SurveyMonkey Flexport Cuebiq Postmates" right after a line that already says "Guardicore → Akamai / TheValidate → SurveyMonkey." Two of the seven marquee names are the acquirers from the line above. To a critical reader this reads as padding.
- (b) `app/(foyer)/page.tsx:71-79` + `RevenueTick.tsx:96-105`.
- (c) Drop Akamai and SurveyMonkey from the marquee. The marquee should be the companies you BUILT AT, not the companies that bought your companies. Names that earn their place: Guardicore, TechValidate, Flexport, Cuebiq, Postmates. Five is enough.

### M6 — Parallax touch-detection misclassifies touch-capable laptops.

- (b) `components/color-worlds/WorldSwitcher.tsx:96-113`.
- (c) Filter `entries` to only the entries where `isIntersecting === true`, then sort by `Math.abs(rect.top + rect.height/2 - innerHeight/2)`, take the first, and apply only that one. Same fix as the initial-state code at lines 76-94 — generalize that into a `pickCentered(sections)` helper.

### M9 — `Hero` mousemove writes inline transform that overrides any GPU optimization.

- (c) Add `will-change: transform` to `.cw-h1` in CSS; rAF-batch (see H6); consider moving the parallax to a wrapper `<div>` around the H1 so the text-shadow rendering surface doesn't move per frame.

## LOW

### L1 — Open item: rolling-word color. Recommendation: keep bone + italicize.
The two gold options (`#F0C25A` and `#FFB511`) both shift the eye away from the verb "build" toward a sunset accent before the noun arrives. The espresso fail-AA is real. Bone + italic preserves the rhythm-change (italic *is* a tonal shift), keeps the contrast well above AA-large, and reads more "operator" than "designer." Pick bone + italic.

### L2 — Open item: eyebrow copy. Recommendation: drop "AVAILABLE NOW."
"Independent builder — Oakland, CA" stands alone. The full hero is the availability signal; the eyebrow trying to also be a calendar-status reads anxious. Both alternatives ("BOOKING Q3 2026" or drop) are stronger than the current — dropping is cleanest.

### L3 — `cw-revline` copy is inverted: "$17M+ in revenue, generated."
- (a) The comma + "generated" is doing the work of a period in a sentence that ended one word ago.
- (b) Same component.
- (c) "**$17M+ generated in revenue.**" Or just "**$17M+ in revenue.**" The "generated" word is a holdover from an earlier draft.

### L4 — Footer carries the second `.cw-shift` aberration on "LET'S BUILD."
- (a) The brief allowed one aberration per page; this is the second. It's effective as a bookend — but worth flagging that this was a conscious second use, not an accident.
- (b) `app/(foyer)/page.tsx:234`.
- (c) Keep, but document the choice in the component comment.

### L5 — Companies marquee meta line: "Attributions under NDA" reads defensive.
- (a) Two attributions are already named. Leading the meta line with NDA disclosure undercuts the confidence.
- (b) `app/(foyer)/page.tsx:209-212`.
- (c) Drop "Attributions under NDA" entirely, or move it to a small footer footnote ("Detailed engagements under NDA — happy to discuss live"). The home page should not advertise its own redactions.

### L6 — Hero parallax range is too aggressive for the type scale.
- (a) `dx * 20, dy * 12` on a headline that hits 196px at the high end means visible 20px drift. Reads as instability rather than as the intended "depth."
- (b) `components/color-worlds/Hero.tsx:113`.
- (c) Cut to `dx * 6, dy * 4`, or kill the parallax entirely. The chromatic aberration alone is already doing the "type has weight" work.

### L7 — Lenis on the home is fighting the section snap intuition.
- (a) Each Color World should land like a turned page. Lenis adds inertia that delays the section-center moment and softens the world-cross-fade trigger. On a long-scroll site where each section is a distinct color, snappier scroll lands better.
- (b) `components/LenisProvider.tsx`.
- (c) Test with Lenis disabled. If you keep it, tune `duration` low and `easing` snappier than default.

### L8 — Hero mobile menu button label "Menu —" ends in a stray em-dash.
- (a) Reads as a typo on tap. The dash isn't a separator (no second half) and isn't an underline (no length).
- (b) `components/color-worlds/Nav.tsx:62`.
- (c) Change to "Menu" or "Open menu" or use a proper icon. The dash isn't adding anything.

### L9 — Double "Book a call" CTA semantics.
- (a) Hero CTA "Book a call →" anchors to `#contact`. Footer CTA "Book a call ↗" opens mailto. Two visually identical labels with two different behaviors. The "↗" hint is subtle.
- (b) `Hero.tsx:160-161`, `page.tsx:240-246`.
- (c) Distinguish: hero label "See how I work ↓" (or just "Scroll"), footer label "Book a call" with the mailto. Two CTAs called the same thing on the same page is confusing.

### L10 — Slash separator in the exits line.
- (a) ` / ` between "Guardicore → Akamai" and "TheValidate → SurveyMonkey" competes visually with the underlined company names. The slash is a 90° tilt against the otherwise-horizontal rhythm.
- (b) `RevenueTick.tsx:99-102`; `globals.css:5779-5791` (mobile breaks the separator to its own line).
- (c) Use ` · ` (middle dot) or ` — ` (em-dash with spaces). The slash is the loudest separator in the punctuation library and you don't need that volume here.

## Net read

**Not shippable as-is for a $200k+/yr consultant's portfolio.** The direction is sound — terracotta + petrol + bone + espresso is a real palette, the texture stack reads as deliberate, the rolling-word effect actually lands, the brand voice is operator rather than designer. A senior peer would see the bones of a strong site. But the credibility moment is broken in three places at once: the second exited company is misspelled, the revenue line ships as `$0.0M` server-side, and the sitemap still points Google at four orphaned routes that render as foyer Frankenstein pages.
