# The 80% Wall — Companion Files

The working versions of everything in the manual. Copy them into your
repo and edit; nothing here is sacred except the habit of keeping them.

- templates/   SPEC.md (blank + three filled examples), the invariants
               starter, USERS.md, LOOP.md, .env.example, and a sample
               architecture doc.
- checklists/  All ten pre-flights, one file each, ready to run.
- prompts/     Prompt files for Claude Code, Cursor, and any agent
               that reads instructions. Paste or reference by path.

Start with templates/SPEC-template.md and checklists/01. Everything
else earns its place as your build grows.
