# Pre-flight - The hand-off (chapter 10)

- [ ] Score the five signals quarterly, in writing: queue, ceiling, skill, dread, bus-factor.
- [ ] Choose on purpose: "keep going" is a decision with a date, recorded in the spec NOW.
- [ ] Before any hire, write the job as rules-with-reasons; if a file and a check can do it, ship those.
- [ ] Rent senior judgment by the milestone: season, outcome, and done, defined before the search.
- [ ] Keep the repo sale-ready even if you never sell: these files are the data room.
