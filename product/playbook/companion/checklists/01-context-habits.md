# Pre-flight - The five habits (chapter 1)

- [ ] Write the invariant list: one file in the repo root, one line per rule-with-a-reason. Thirty minutes, tonight.
- [ ] Point every session at it first: "Read the invariants file before you touch anything."
- [ ] Read every diff before accepting. A diff touching a file your change had no business touching = stop and ask why.
- [ ] One change per commit, committed the moment it works. Rolling back beats an apology prompt.
- [ ] Caught the AI breaking a rule? Write the rule down the same day, and turn it into a machine-run check where you can.
