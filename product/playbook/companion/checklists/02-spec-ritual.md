# Pre-flight - The spec ritual (chapter 2)

- [ ] Write SPEC.md tonight: six sections, one page, hard cap.
- [ ] Open every session with it: "Read SPEC.md and the invariants file, then the task."
- [ ] Frame asks against NOW: "Per the NOW milestone, build X."
- [ ] Treat every "should I also..." as a NOT lookup; genuinely new ideas go to LATER, deliberately.
- [ ] Change the spec only in its own commit. A spec edit riding inside a feature diff is drift with paperwork.
